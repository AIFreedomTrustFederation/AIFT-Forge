# AIFT Forge UNIX Manual Manual

This directory contains the UNIX-style manual source for this repository.

Manual source belongs to this repo. PDF and publication builds belong to BookSmith.

**Source coverage:** The [manual manifest](../../.aift/manual.json) marks `manualSource` as `ready` and lists `man0` through `man9`, but only [`man0`](source/man0/00-introduction.md) and [`man7`](source/man7/truthfulness.md) contain authored pages in this revision. The other eight categories are reserved in the [manual index](source/index.md), not completed chapters. PDF building and web publication remain `planned`; source readiness does not prove a generated, approved, or published manual.
